# איך החבילה הזאת יושבת כאן, ומה מותר לעשות בה

החבילה הזאת היא **קוד הייחוס של ענבל**, גרסה שב-`VERSION`. היא נכתבה בנפרד
מהקבצים של ניל, ושורות "דורש התאמה בקוד אצל ניל" בהערות מפנות אליה בשם
המודול. `README.md` שלצדה הוא שלה, והוא מתאר מה כל מודול עושה ואיזה שינוי
בהערות הוא מממש. הקובץ הזה הוא שלנו, והוא מתאר רק את ההשתלבות.

## למה היא כאן ולא בכל סקיל בנפרד

המודולים מייבאים זה את זה: `orchestrator` ו-`playbook` ו-`risk` מייבאים
מ-`common`. הפלאגין נטען כשורש אחד (`${CLAUDE_PLUGIN_ROOT}`), ולכן ספרייה
משותפת אחת כאן עובדת לכל הסקילים, ואין צורך לשכפל אותה לתוך כל אחד מהם.
השכפול הזה כבר קיים בחבילה בשני מקומות (`contract-drafter/scripts/core/`
ו-`legal-contract-translator/scripts/core/` הם אותם שני קבצים), והוא מה
שאנחנו רוצים להפסיק ולא להרחיב.

## איך סקריפט של סקיל מייבא מכאן

```python
import sys
from pathlib import Path
sys.path.insert(0, str(Path(__file__).resolve().parents[3] / "lib"))

from common.paths import safe_out_paths     # noqa: E402
from orchestrator.qa_gate import run_gate   # noqa: E402
```

`parents[3]` מתיקיית `scripts` של סקיל הוא `areolegal/`, ולכן `lib` שלידה.
`scripts/areo_lib.py` בכל סקיל שצריך את זה עושה את השורות האלה פעם אחת,
וסקריפט מייבא אותו ראשון.

## המבנה נשמר מילה במילה, בכוונה

שמות התיקיות, שמות המודולים ותוכן הפונקציות הם כפי שענבל מסרה. כל שינוי
מקומי מסומן בהערה בגוף הקוד ורשום כאן למטה. כך רענון לגרסה הבאה שלה הוא
diff ולא מיזוג מחדש.

**מה שכן מותר:** תיקון באג, עם הערה שאומרת מה תוקן ושהוא דווח.
**מה שאסור:** לשנות שמות, לפצל מודולים, או לשלב קוד שלנו לתוך המודולים.
קוד שלנו יושב ב-`scripts/` של הסקיל ומייבא מכאן.

## השינויים המקומיים שנעשו כאן

| מה | למה | דווח |
|---|---|---|
| `common/net.py`, שורת `final` בטיפול ב-`HTTPError` | `geturl()` נכשל ב-`KeyError` כששגיאת ה-HTTP נבנתה בלי גוף תשובה, וזה בדיוק מצב ה-403 שהפונקציה מטפלת בו | כן |
| `tests/test_orch_49.py`, בדיקת גבול הנתיב | הבדיקה בנתה נתיב בסגנון Windows, ו-`check_write_path` מודד `os.path.abspath`. על macOS ולינוקס נתיב כזה אינו מוחלט, ולכן האורך שנמדד אינו מה שהבדיקה התכוונה אליו. התיקון בבדיקה: הנתיב נבנה מוחלט בפלטפורמה שרצה | כן |
| שם הלקוח ומספרי החברה בפיקסצ'רים ובעזרי הבדיקה | הריפו הזה ציבורי. `HIGHLAW` הוחלף ב-`EXAMPLECO` (99 מופעים), מספר החברה ב-`511111114` (עובר את ספרת הביקורת, כי בדיקה אחת מאמתת אותו), המספר הפסול ב-`11111111`, ושם עורכת הדין ב"פלונית אלמונית" | כן |

## הרצת הבדיקות

```bash
python3 -m venv /tmp/areo-lib-venv
/tmp/areo-lib-venv/bin/pip install python-docx lxml pymupdf Pillow pytest
cd areolegal/lib && /tmp/areo-lib-venv/bin/python -m pytest tests -q
```

מצב ירוק: **407 עברו, אחת דולגה**. הדילוג היחיד הוא בדיקת ההדדיות מול Word
עצמו, שרצה רק עם `AREO_WORD_CHECK=1` ודורשת Word מותקן.

`release.sh` מריץ את החבילה הזאת לפני כל שחרור, ובונה את הסביבה בעצמו.

### התלויות אינן שוות ערך

- **pymupdf דרוש, pypdf אינו מספיק.** `risk/page_text.py` מעדיף pymupdf
  ונופל ל-pypdf, ושכבת הטקסט של pypdf מחזירה עברית בסדר חזותי ולא לוגי.
  עם pypdf בלבד שלוש בדיקות נכשלות במקום להידלג.
- **Pillow** דרוש לשתי בדיקות של הלוגו.
- **Chrome** דרוש לבדיקות הרינדור של דוח הסיכונים, והן רצות כשהוא מותקן.
