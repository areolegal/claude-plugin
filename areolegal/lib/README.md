# הספרייה המשותפת של Areo (`AREO_RT/lib`)

הספרייה המשותפת לכל הרכיבים שהסקריפטים שלהם בשירות. היא מגיעה בחבילה `areo-runtime.zip`, ונפרסת בתיקייה זמנית של המחשב (`AREO_RT/lib`), לעולם לא בתיקיית הלקוח. הגרסה ב-`VERSION`; כתובת הקשר של המזהה ברשת ב-`config.json`.

**סביבה:** Python 3, ספריית התקן, python-docx ו-lxml בלבד.

**כלל לכל המודולים:** כל בדיקה וכל כלל כלליים לכל סוג הסכם, לכל צד, לכל דין ולכל לקוח. מה שתלוי בסוג ההסכם, בלקוח או בדין מגיע בזמן ריצה מהפרופיל, מהפלייבוק, מקובץ המצב או מההסכם עצמו.

## common: ספריות משותפות

| מודול | מה הוא עושה |
|---|---|
| `common/branding.py` | צבעי המותג של הלקוח, מהפרופיל לנתוני תוצר HTML (`meta.branding.theme`). |
| `common/case_law.py` | פסיקה רק ממחבר פסיקה סגור (כלל 1.1): `case_law_url` (אתר בית משפט, מאגר פסיקה, מדור פסיקה באתר מאושר), `case_law_hits` ו-`case_law_problem` (אזכור פסק דין בטקסט), `case_law_in_data`. |
| `common/cli.py` | ממשק אחד לכל נקודת כניסה, ושמירה על קובצי הקלט של הלקוח (`guard_out`, `write_json`). |
| `common/docx_tracked.py` | מנוע עקוב אחר שינויים ב-Word, אחד לכל הרכיבים. |
| `common/gap_checks.py` | בדיקות "נוסח שאנחנו כותבים אינו יוצר פער", בעברית ובאנגלית. |
| `common/ids.py` | מספר תאגיד ומספר זהות ישראליים: פורמט, ספרת ביקורת, והשוואה לפרופיל ולמסמכי החברה. |
| `common/net.py` | שכבת הגישה האחת לרשת: מזהה גלוי, קצב, עצירה בחסימה, כללי כתובת (דומיין, תת-דומיין ונתיב, לפני הבקשה ואחרי הפניה), ודחיית כל כתובת פסיקה. |
| `common/paths.py` | נתיבי פלט בטוחים ונתיבים ארוכים ב-Windows. |
| `common/rtl.py` | RTL מלא בקובצי Word בעברית, ובדיקה של קובץ שמור. |
| `common/terms.py` | התאמה של מונח לפי גבולות מילה, גם בעברית. |
| `common/vague_terms.py` | מונחים עמומים: רשימה אחת לנושא ונותן ולמעריך הסיכונים. |

## risk: מעריך הסיכונים

| מודול | מה הוא עושה |
|---|---|
| `risk/build.py` | בניית הדוח וכתיבתו לתיקיית העסקה, עם המרשם לצדו; שם הקובץ לפי שפת הדוח. |
| `risk/entity_store.py` | שמירת עותקים גולמיים של בדיקת הרקע בתיקיית העסקה, בלי רשימות מלאות ובלי טוקנים. |
| `risk/extract_corpus.py` | חילוץ מסמכי Word לקובץ ביניים. |
| `risk/logo.py` | הלוגו מהפרופיל כתמונה מוטמעת. |
| `risk/page_text.py` | הטקסט של עותק גולמי (HTML, טקסט או PDF) ונרמול לבדיקת ציטוטים. |
| `risk/render_check.py` | בדיקת הדוח בדפדפן בלי ממשק: עמודים, שגיאות, בקשות לרשת וסימון החיסיון. |
| `risk/validate_register.py` | הבדיקה הממוחשבת של `risk-register.json` ושל `entity-report.json`, כולל המקורות מול `מקורות-מאושרים.json` (בלי רשימת נפילה) ואזכורי פסיקה בלי מחבר סגור. |
| `risk/resources/entity-report-template.html` | עותק זהה של תבנית דוח בדיקת הרקע של מעריך הסיכונים. |
